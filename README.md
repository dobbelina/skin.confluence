# confluence 5.0.9 kodi 22 compatible 
The skin is now compatible with kodi 22.

Files modified:
- IncludesCodecFlagging.xml
- VideoFullScreen.xml
- Includes.xml
- Added new: av1.png, rv40.png, theora.png, fps.png, missing: 8K.png
- Changed: 480.png, 540.png, 576.png
- Added fps basge
- Renamed skin.confluence.special

The skin now shows the missing audio quality badges and codec images in the player OSD menu.
  
Fixed inconsistent library xvid listing.  
  
Download here: [skin.confluence.special-5.0.9.zip](https://github.com/dobbelina/skin.confluence/releases/latest/download/skin.confluence.special-5.0.9.zip)
